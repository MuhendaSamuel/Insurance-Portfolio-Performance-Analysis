
# Insurance Portfolio Performance & Risk Analysis

## Project Overview

This project analyses an insurance portfolio using SQL Server and Microsoft Power BI to evaluate portfolio performance, premium collections, claims experience, underwriting risk and policy renewals.

The objective is to transform relational insurance data into meaningful business insights that can support management reporting, performance monitoring and informed decision-making.

## Business Objectives

The analysis focuses on:

- Evaluating policy distribution and premium contributions across insurance products.
- Assessing premium collection performance and outstanding receivables.
- Comparing collection performance across agents and branches.
- Examining claims distribution and claims experience.
- Evaluating underwriting decisions and portfolio risk.
- Assessing policy renewal performance.

## Tools & Technologies

- SQL Server:Data querying, analysis, aggregation and business performance calculations.
- Microsoft Power BI: Interactive dashboard development and data visualisation.
- Microsoft Word: Analytical reporting and documentation.

## Key Findings

The analysis covered 8,000 insurance policies and identified several important findings:

- Total recorded policy premiums amounted to 1,222,182.92.
- Health insurance contributed the highest recorded premium value.
- A total of 100,000 invoices were analysed.
- Total invoiced amounts stood at 15,245,969.85.
- Total collections amounted to 14,034,068.72.
- Outstanding receivables stood at 1,211,901.13.
- The overall premium collection rate was 92.05%.
- Approximately 88% of outstanding receivables were more than 90 days overdue.
